# ITSM Portfolio — Incident Management & SLA Analysis

## Project Overview

This self-directed IT Service Management (ITSM) portfolio project demonstrates incident data analysis, SLA monitoring, incident prioritization, and service improvement concepts using a fictional banking environment.

## Project Objectives

- Analyze a dataset of 200 simulated IT incidents.
- Review incident priorities, statuses, and resolution information.
- Assess SLA compliance and identify potential performance issues.
- Prepare an Excel-based incident performance dashboard.
- Develop practical recommendations for improving incident management.

## Tools and Skills

- Microsoft Excel
- Incident Management
- ITIL concepts
- SLA monitoring and reporting
- Data validation and KPI analysis
- Service improvement recommendations

## Dataset

**File:** `Northstar_Bank_ITSM_Incident_Dataset_200.xlsx`

The dataset contains fictional incident records created for learning and portfolio demonstration. Northstar Bank is a fictional organization. The data does not represent real customers, production incidents, or employer records.

SLA targets in the dataset are illustrative and intended for this exercise, not universal ITIL standards.

## Planned Deliverables

1. Dataset validation and data quality checks
2. Incident KPI calculations
3. SLA compliance analysis
4. Excel dashboard
5. Incident management improvement recommendations
